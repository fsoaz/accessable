# Roadmap

## Hackathon MVP delivered

- Bundled event registration fixture with measured axe and keyboard baseline findings.
- Deterministic HTML patch generation, review, and single-use approval.
- Fresh browser verification, side-by-side previews, patch download, and reset.
- Saved replay with no AI credentials and a configurable eve adapter for live proposals.

## Remaining validation

Exercise **Generate live proposal** with an AI Gateway credential. Confirm that the model returns a schema-valid proposal and that the reviewed live patch passes the same browser checks as replay. [Current task](../execution/current_task.md)

## Follow-on scope

Arbitrary URL audits, project or repository imports, multi-page scans, broader repair coverage, and hosting are deferred. Each would change the MVP's assumptions about page ownership, source mapping, or run isolation.
